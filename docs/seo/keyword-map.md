# Keyword ownership map (23 Oct 2026)

One keyword, one page. Enforced by `npm run check:keywords` (part of `npm run check`). The service page owns the commercial query (for example "GoHighLevel agency"); each post owns one informational task and links up to its service page.

When adding a post: pick a primary keyword no other page uses, keep secondaries to variations of that same task, and run the check. If a query already belongs to a page, improve that page instead of writing a second one.
