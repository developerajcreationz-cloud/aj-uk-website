# Search Console verification and sitemap

## 1. Verification (HTML tag) - done in code

The tag is in the `<head>` of every page, rendered by Next.js metadata in `src/app/layout.tsx`:

```html
<meta name="google-site-verification" content="Yp0JS38ugKIipb5Dze06h2fRRWb8XHbVmPbuiV65Ye0" />
```

Do not remove it, even after verification succeeds. To override it later, set `GOOGLE_SITE_VERIFICATION` in Hostinger's environment variables.

**Steps**

1. Push is auto-deployed by Hostinger (GitHub `main`). Wait for the build to finish, then open `https://ajcreationz.co.uk/` and View Source to confirm the tag is there.
2. In Search Console choose the property type **URL prefix** and enter `https://ajcreationz.co.uk/` (HTML-tag verification only works with URL-prefix properties), then click **Verify**.
3. Add `https://www.ajcreationz.co.uk/` only if you want to watch redirect behaviour. The site redirects www to the bare domain with a permanent redirect.
